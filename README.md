# INDIA-VS-UK-ANALYSIS-ON-WHAT-S-AVAILABLE-ON-NETFLIX
This project analyses the shows available on NETFLIX in both India and UK. Coming to India in the holidays, they always have or don't have shows I don't watch., which  I always explore each time I go there.Here I have performed an analysis between these two countries based on the shows they have, as well as the overall trends between them.
